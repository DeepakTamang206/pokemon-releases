## 🔄 Automatic In-Game Updates

The game features a built-in auto-updater! Whenever a new update is released:
- Launching game.exe notifies you via audio chime and screen reader.
- Press **Enter** to download the update with spoken progress.
- The game automatically applies the update and restarts.
- Your save data and settings are always safely preserved.
