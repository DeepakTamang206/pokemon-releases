# Pokemon Dark Dungeon - Official Public Releases

Welcome to the official release repository for **Pokemon Dark Dungeon**, an accessible 3D audio adventure designed for blind, visually impaired, and mainstream audio game players.

## How to Play & Install

1. Download the latest game.zip from [Releases](https://github.com/DeepakTamang206/pokemon-releases/releases).
2. Extract the zip archive anywhere on your PC.
3. Run game.exe.

## In-Game Auto-Updates

The game features built-in automatic updates! Whenever a new build is published:
- Launching the game will notify you of the new version.
- You can press Enter to download and install automatically with voice progress narration.
- Your save data and settings are safely preserved.
